# AtBD+ (Atende Bem D+)

MVP de um sistema web para registrar pedidos e acompanhá-los entre o salão e a cozinha de um restaurante pequeno e recém-aberto.

## Problema
Os pedidos são anotados à mão, o que causa erros de anotação, comandas perdidas, pratos refeitos e desperdício de alimentos.

## Público
- **Usuários:** garçons e cozinha.
- **Beneficiados:** funcionários, dono do restaurante e clientes.

## Diferencial
Um sistema enxuto, focado no fluxo do pedido (registrar, enviar à cozinha e acompanhar até a entrega), que dispensa um sistema de gestão já implantado.

## Tecnologias
- Python 3.12
- Django 5.2 LTS
- MySQL
- Bootstrap

## Como executar
Instruções em construção. Serão adicionadas conforme o ambiente for configurado.
